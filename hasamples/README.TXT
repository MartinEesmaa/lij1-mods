COLLECTION.TXT

Just copy the CHARS folder to LIJ1's root game folder to install it.
Also please see the template folder called "TEMP_STUFF/TEXT/ENGLISH.TXT" look like this:

```
198 "Monkey Man"
199 "Mine Cart"
201 "Arnold Shortman"
202 "Gerald Johanssen"
```

Add these three entry lines of 201, 202 and 203 as name IDs to `STUFF/TEXT/ENGLISH.TXT`:

```
201 "Arnold Shortman"
202 "Gerald Johanssen"
203 "Helga Pataki"
```

NOTE: If you have more multiple mods installed, please replace 201, 202 and 203 by any name IDs of 200-294:
Needs to be changed files:

```
STUFF/TEXT/ENGLISH.TXT
CHARS/ARNOLDSHORTMAN/ARNOLDSHORTMAN.TXT
CHARS/GERALDJOHANSSEN/GERALDJOHANSSEN.TXT
```
